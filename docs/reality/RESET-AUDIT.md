## Residual entry and ownership risks

- `src/main.js` passes the query parameter into standalone composition; `src/standalone/application.js` suppresses Austin startup, creates the mission launcher and opens Tonga. Remove the entire active dependency chain, including CSS imports, rather than only hiding the launcher button.
- `Start-Reality.ps1` opens `/?situation=tonga`; `Start-Cyber.ps1`, the static-server banner and README expose retired destinations. Point the supported launcher and demo links at native `/`. Keep archived commands clearly identified as archives if retained.
- The old mission's exit handler uses `history.replaceState({}, '', location.pathname)`, which discards unrelated query parameters and the upstream share hash. Native `sharelink.js` encodes camera/layers/style in that hash. A new debug-session clear must preserve shared view state, current camera and user-owned layers. A stale `?situation=tonga#...` must restore the native hash normally.
- `body.reality-active` and `.story-mode` hide ordinary UI and selected labels. Their old styles can stay unimported in archives; neither class nor its behavior belongs in the native layer. Do not globally clear native annotations when clearing a debug session.
- The globally offered mission voice tool remains discoverable even with its launcher removed. Disable/rework both schema and server description, plus runner injection. Returning “open a mission” is a product regression, not a valid debug-session error.
- Vite provider middleware is not Vercel production code. `vercel.json` currently emits a static site; new live outage access must either work through the verified public browser endpoint/CORS contract or have a real deployable bounded proxy. Missing `/api/*` must not fall back to HTML with HTTP 200. Do not expose a secret or create an unrestricted fetch proxy to solve access.

## Native seams already present

`src/app/layers/earthquakes.js` wires a source-driven layer to the shared overlay host; `src/layers/earthquakes/index.js` owns initialization, independent enable/disable, refresh cancellation and data-source lifetime. `src/app/layers/submarineCables.js` supplies the native cable implementation. These are appropriate patterns for Internet Health and contextual cable reveal.

`src/data/contextStore.js` registers entities and publishes selection through `gev:entity-selected`. The existing tracked-subject helpers deliberately have a separate notification lane while sharing the selected-context slot. Internet Health must register stable source-backed IDs and participate in the native selection contract, not replace it. A debug action must capture the current selected record and camera/layer context at invocation; selection changes or clear must cancel stale async results.

## Additional delivery gates

Verify provider access, timestamps, geographic coverage, terms, refresh policy and errors from the real endpoint before calling the layer live. Preserve stale snapshots as explicitly stale if appropriate; an empty/error response is not evidence of healthy Internet. If no current anomalies are available, disclose that state and wait or broaden a documented recent window rather than fabricate demo records. A “biggest outage” command must use a source-defined comparable metric or explain that ranking is unavailable.

Exercise the same production entry and source path intended for deployment. Run focused source/normalization/lifecycle/selection tests, upstream regression and boundaries/format/build checks. Capture milestones in the real browser, then a 60–90 second free-order operator demonstration using current/recent records. The recording is evidence of flexible interaction, not a new authored historical sequence. No prior Tonga/story acceptance substitutes for these checks.

## Native-reset milestone

`scripts/qa-native-reset.mjs` exercised the plain static production build at port 4180. All ten corrected assertions passed: the stale mission/story query could not mount the retired UI, unrelated query data and semantic shared-camera state survived, native controls and the single viewer remained, pointer navigation moved the camera, and the existing earthquake layer enabled and disabled independently. The live USGS feed returned HTTP 200; no unhandled application exception occurred. Optional static-host endpoints returned 404/405, recorded separately.

The screenshot in `validation/native-reset/native-reset.png` was opened and inspected: ordinary God's Eye View branding, native layer rail and world controls are restored, with a real earthquake label visible. The first harness run incorrectly expected an identical raw hash; upstream legitimately canonicalized it while preserving camera values. That failed report is retained alongside the corrected semantic comparison. This milestone did not select an arbitrary native context record and does not establish Internet Health or A–N acceptance.
